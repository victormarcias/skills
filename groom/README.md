# groom

`/groom` goes through the questions and decisions left open in the
conversation, one by one, as multiple-choice questions with a recommended
option. Each question comes with clickable links to the URLs it is about,
VS Code links to the files with large changes, and a table or chart only when
it makes the choice clearer. Use it
after a report or review that ended with several open items.

Each answer is applied before the next question, as uncommitted changes in
the working tree. It touches only the files the decisions are about.
Instructions: [SKILL.md](SKILL.md).
